# VibeLeading Organization Profile

This is the special `.github` repository for the **VibeLeading** GitHub organization.

The org profile page displayed at https://github.com/VibeLeading is rendered from
[`profile/README.md`](profile/README.md).

The repository has no code — it only exists to surface the organization's profile and,
optionally, shared community health files (such as default `CODE_OF_CONDUCT.md`,
`CONTRIBUTING.md`, or issue/PR templates) in the future.
